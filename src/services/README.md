# src/services — servisni sloj (poslovna logika)

Ovde su klase servisa (TicketService, CommentService, ...) i politike (`policies/`). Servisi ne znaju za HTTP; dobijaju `ServiceContext` kroz konstruktor i bacaju `AppError`.
Opis klasa: `docs/03-dijagram-klasa.md`, sekcija 3. Faza 4: `auth/` (AuthService) i `profile/` (ProfileService). Faza 5a: `policies/` (StatusTransitionPolicy, TicketAccessPolicy), `tickets/` (TicketService, pretraga), `comments/`, `ratings/`, `categories/`, `admin/` (UserAdminService: spisak agenata; u Fazi 8b lista naloga i izmena uloge/aktivnosti) i `shared/` (učitavanje imena i kategorija, slanje real-time događaja). Faza 6: `dashboard/`. Faza 7: `notifications/`. Faza 8: `analytics/` (AnalyticsService i čiste funkcije za pretvaranje redova); u 8b `CategoryService.create/update` i `UserAdminService.list/update`. Ostali servisi u kasnijim fazama (`docs/07-uputstvo-za-implementaciju.md`).
